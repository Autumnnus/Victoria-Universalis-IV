# Group idea modifiers. One modifier per idea, added permanently by boost_<group>_idea_effect
# in common/scripted_effects/ve_idea_effects.txt. Tooltips are auto-derived from these
# definitions by idea_N_tt_effects in common/scripted_effects/ve_idea_tooltip_effects.txt.
#
# Manually maintained. Design roles and power bands are documented in
# IDEA_GROUP_BALANCE.md. Keep edits consistent with these balance rules:
#   - modifier values are budgeted by gameplay leverage, not raw modifier count
#   - idea 7 is the capstone: strongest, and carries the modifier that defines the group
#   - each group has one primary strength, supporting strengths, and a known weakness
#   - pool resources (bureaucracy, authority, prestige, influence, tech spread) use _mult,
#     never flat _add, so they still matter in 1936
#
# nationalist ideas 5 and 7 are effect-driven (religious missionary mechanic) and carry no modifier;
# their tooltips come from nationalist_idea_5_tt / _7_tt.
#
# DO NOT split nationalist idea 2. common/script_values/missionary_value.txt
# evaluates nationalist_idea_2_mdf throughout the live Missionary Power formula.
