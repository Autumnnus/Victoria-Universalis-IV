# Group idea modifiers. One modifier per idea, added permanently by boost_<group>_idea_effect
# in common/scripted_effects/ve_idea_effects.txt. Tooltips are auto-derived from these
# definitions by idea_N_tt_effects in common/scripted_effects/ve_idea_tooltip_effects.txt.
#
# Manually maintained. Keep edits consistent with the active mechanics and balance
# notes in MECHANICS_REFERENCE.md:
#   - one idea = one unit of power; if an idea carries two modifiers, each is half strength
#   - idea 7 is the capstone: strongest, and carries the modifier that defines the group
#   - a modifier type belongs to exactly one group, so each group keeps a distinct identity
#   - pool resources (bureaucracy, authority, prestige, influence, tech spread) use _mult,
#     never flat _add, so they still matter in 1936
#
# Nationalist ideas 5 and 7 are effect-driven through the piety, religious
# project and cultural project values (see ve_religious_project_values.txt and
# ve_cultural_project_values.txt). Their
# modifiers are ownership markers only: the mechanical effect remains variable
# driven. The Ideas panel checks nationalist_idea_5_var / _7_var directly so
# legacy empty markers cannot make a cancelled idea look active.
#
# Nationalist idea 2 intentionally contains only the passive conversion and
# assimilation multipliers; project outcomes are granted by idea VII instead.
